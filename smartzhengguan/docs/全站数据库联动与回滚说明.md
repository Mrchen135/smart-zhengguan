## 页面与接口

下表接口均以 /api/v1 为前缀，除公开的虚构隐私样本外，业务和账号接口需要真实登录。

| 页面 | 接口 | 数据来源或保存行为 |
| --- | --- | --- |
| 登录 | POST /auth/token/、/auth/me/ | Django 用户、JWT 登录，记录登录时间与操作 |
| 首页 | /home/ | 年度、年级专业、生源汇总表及业务待办；已有年度汇总与学生档案为不同统计口径 |
| 招生管理 | /admission/ | AdmissionCycle、AdmissionStageProgress |
| 学籍总览 | /academic-status/ | Student、AcademicStatusEvent；编辑通过 PATCH /academic-status/records/{external_id}/ 保存 |
| 学籍异动管理 | /academic-change/ | AcademicChangeRequest，读取与详情 |
| 培养总览 | /training/ | TrainingPlan；筛选结果可导出 CSV |
| 课程管理 | /training-course/ | CourseOffering，读取与详情 |
| 学位总览 | /degree/ | DegreeApplication 等业务表 |
| 答辩管理 | /degree-defense/ | DefenseSession，读取与详情 |
| 奖助管理 | /scholarship/ | ScholarshipAward |
| 就业管理 | /employment/ | EmploymentRecord |
| 群体画像 | /cross-module-query/ | Student、奖助、培养、学位、就业记录；有档案的组合以档案人数为准 |
| 个人画像与智能预测 | /intelligent-prediction/、/analyze/、/chat/、/chat/stream/ | 学生档案、PredictionSnapshot、月度指标、规则和本地知识库；仅有数据库快照的学生进入预测列表 |
| 全局搜索 | /search/、/search-history/ | 搜索数据库业务记录；历史按账号保存、读取和清空 |
| 数据管理 | /upload/*、/export/* | 批次、字段映射、模板、导入/撤销、导出记录与文件下载 |
| 系统设置 | GET/PATCH /system-settings/ | WorkspaceSetting；默认登录入口、批次分页条数；管理员可修改 |
| 个人中心 | GET/PATCH /personal-center/ | 当前账号资料、AccountActivity；角色与账号不可在个人资料中变更 |
| 修改密码 | GET/POST /change-password/ | 校验旧密码与新密码强度，更新密码哈希，撤销旧令牌效力 |
| 导航消息 | GET/POST /notifications/ | ModuleNotice、NoticeRead；已读状态按账号保存 |
| 隐私协同 | /privacy-collaboration/scenarios/、/inspect/、/execute/ | 继续使用隔离的虚构样本；PrivacyExecution 保存当前账号的审计元数据，刷新后可读 |
