# 端云任务工作台与跨年级画像（2026-11-23）

## 发布具体分析任务

入口：左侧“隐私协同” → “发布分析任务”。

1. 填写任务名称、年级、专业、分析主题及具体要求。
2. 点击“发布任务并检查数据”。系统保存任务和当时的统计快照。
3. 核对实际范围、人数、演示记录人数，展开查看拟发送的任务文本与统计内容。
4. 选择“云端辅助解读”或“本地统计”，点击“执行任务”。
5. 在“最近发布的任务”中重新打开、复制为新任务、下载结果。

例：选择2025级、全部专业、培养进展，要求“概括课程、学分与培养现状，并给出导师本周可执行的三项安排，每项写明数据依据”。

当前支持培养进展、毕业去向、科研实践、综合对比等分析任务。任务不会自动发送通知、修改学生档案或指派人员。当前数据库的演示数据来源标记保留。

任务列表与明细仅限当前登录账号。服务端读取并生成统计快照，不接受浏览器自带统计数据。问题文本出现可识别个人信息，或统计分组/互补分组不足5人时留在本地。判断不能保证任意自由文本完全匿名，执行前展示完整拟发送内容，提示不要输入个人信息。

结果显示真实的本地、云端或回退状态。重复执行已完成任务返回已保存结果，不再次调用模型。等待超时后重新读取任务记录，服务端中断的任务可复制重试。

培养进度不等于是否按期；未提供阶段目标、选课原因或个体学分分布时，不据此判定整体落后、选课瓶颈或对个人发出预警。模型分析仍需结合培养方案复核。

## 同专业跨年级画像

只选专业时，摘要下方直接展示六张对比图：去向构成、培养与学分、雷达图、人数性别、奖助与人均科研散点图、指标热力图；下方保留可直接查看的桑基图和旭日图。

按入学年级排列。点击图形选择对应年级，联动高亮与解读；清除选择可恢复整体。毕业与在读分别解释，就业占比仅使用毕业人数为分母，考公与未知单列。不同入学年级的比较是截面比较，不能当作同一批人的时间趋势。

每张图带口径和结论。基础统计及业务明细仍可展开查看。智能预测原有雷达图布局未在本次改动中调整。
