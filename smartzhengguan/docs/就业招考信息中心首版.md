# 就业与招考信息中心（首版）

更新日期：2026-11-23。

## 入口与使用方式

侧栏“就业管理 → 就业信息中心”，地址为 `http://127.0.0.1:3000/#/employment-opportunities`。原“就业统计分析”保留在 `/employment`。

本页数据由 Django 接口读取 SQLite 数据库，不使用前端模拟公告。学生可以检索和收藏；教师、管理员可以补充/核对公告、设为老师精选、触发同步。收藏归当前账号，精选用于共享信息整理。生成转发摘要只提供复制和下载，不自动向微信、QQ、邮件等发送消息。

## 信息范围与专业筛选

招考分为选调生、公务员、事业单位、人才引进；企业招聘支持央企、国企、民企及单位性质未说明。公告没有明确说明的条件、时间和单位性质保持待核对，不根据名称猜测编制或报考资格。

专业目录与现有系统一致：政治学理论、科学社会主义与国际共产主义运动、中共党史、行政管理、国际政治、国际关系、统一战线学、应急管理。规则区分明确提及、方向相关、不限专业和待核实。专业相关性不是完整报考资格审核，也不是录用概率；仍需核对原公告和附件里的具体岗位。

## 自动更新

本次实际启用 2 个自动来源，首轮成功采集 46 条真实公告：

| 自动来源 | 首版读取范围 | 首轮检查数量 |
| --- | --- | --- |
| 山东大学就业中心各省选调公考栏目 | 最近两页公开公告 | 26 |
| 山东大学就业中心招聘与人才引进栏目 | 当前公开招聘列表首屏 | 20 |

另提供 7 个官方/平台入口，包括国家公务员专题、中央事业单位平台、国资委、国聘等，页面明确显示尚未自动接入的原因。本版不是各省所有官方网站的全量直连；公务员分类及人工补充可用，当前两页转载未包含公务员公告时会显示空结果。企业数据按单位招聘公告计数，正文保留岗位文本和附件链接，尚未逐个解析附件里的岗位行。

正常双击项目原有的“启动.bat”，会先应用数据库迁移和初始化信息源，再启动独立同步进程。同步进程每 12 小时运行一次，服务端运行时持续生效，不依赖用户打开网页。关闭电脑或结束进程后不会继续同步；下次启动项目后恢复。

也可以单独双击“启动就业信息自动同步.bat”恢复同步；重复启动由单实例锁保护。双击“停止就业信息自动同步.bat”请求停止。来源失败不会删除已采集公告。

开发和服务器部署命令（在 backend 目录）：

```powershell
.\.venv\Scripts\python.exe manage.py migrate --noinput
.\.venv\Scripts\python.exe manage.py seed_employment_sources
.\.venv\Scripts\python.exe manage.py sync_employment_sources
.\.venv\Scripts\python.exe manage.py sync_employment_sources --watch --interval 43200
.\.venv\Scripts\python.exe manage.py sync_employment_sources --stop
```

实际接入范围以页面“信息来源”的启用状态和最近成功时间为准。全国各省入口不等于已实现该省所有站点自动采集。公开页面可访问性、robots 规则、网站结构、接口授权不同，需逐源验证。没有获准的接口不冒充已接入。

公开信息采集只访问配置的来源域名，不读取学生表，不向外发送学生姓名、学号、成绩或画像。采集保留来源原文及附件链接，不运行下载文件。缺失或不明确的报名时间不生成确定倒计时。

## API

接口前缀 `/api/v1/employment-hub/`，需要真实账号登录：

| 接口 | 用途 |
| --- | --- |
| GET / | 分页检索公告和企业招聘 |
| POST / | 教师/管理员人工补充 |
| GET meta/ | 筛选目录、数据库统计和管理权限 |
| GET sources/ | 来源状态和最近同步结果 |
| GET/PATCH &lt;id&gt;/ | 详情与人工核对更正 |
| POST &lt;id&gt;/save/ | 当前账号收藏 |
| POST &lt;id&gt;/feature/ | 老师精选 |
| POST digest/ | 生成选中信息的转发文本 |
| GET/POST sync/ | 同步状态、异步触发同步 |

## 回滚

修改前代码与数据库已分别备份到 `.local-backups/employment_hub_before_20261123/`。`baseline.zip` 保存本次开始前的工作文件，包括当时已有的未提交修改；`database-before.sqlite3` 保存迁移前数据库快照。

1. 运行“停止就业信息自动同步.bat”，等待同步结束；停止前后端服务。
2. 双击“回滚就业信息中心.bat”。
3. 重新启动原项目；若使用 dist 部署，重新构建前端。

回滚按清单恢复本次涉及的代码，先保存当前版本以便找回，不重置 Git，不覆盖当前数据库，不删除学生数据及后续导入。新表留在数据库中，旧代码不会访问。若要连数据也恢复到迁移前，请另行确认使用数据库快照，避免覆盖此后新增的数据。
