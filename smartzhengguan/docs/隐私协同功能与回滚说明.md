# 端云隐私协同展示台

入口：左侧菜单「隐私协同」，或「智能预测」页面右上方「隐私协同展示台」。

## 演示步骤

1. 进入页面，选择「公开政策问答」，保留「在样本中加入身份信息」。
2. 点击「检查数据边界」，对比左右载荷，并查看姓名、学号、支持记录的处理明细。
3. 点击「执行任务」，查看本地规则结果和真实的服务端执行记录。
4. 切换「个体风险分析」「小群体保护」，重新检查并执行，观察云端载荷为空、云端未调用。
5. 切换「学院汇总分析」，观察仅允许统计数字外发。
6. 可关闭「加入身份信息」比较字段数量，或导出当前会话的审计元数据。刷新页面会清空会话记录。

## 数据与安全边界

- 本页全部使用后端维护的虚构样本，不读取或修改学生数据库。
- 前端只提交场景标识、是否加入虚构身份、执行方式。自定义学生数据、问题文本、模型载荷和人数阈值会被拒绝。
- 后端按任务重建外发字段白名单，执行时重新检查，不能靠修改浏览器中的检查结果绕过。
- 个体任务始终在本地执行。统计总人数和非零分组人数都要达到服务端阈值，否则整个统计请求留在本地。
- 默认执行本地规则，不调用外部模型。检查通过代表“允许外发”，不代表已经调用云端；实际调用结果以执行记录为准。
- 云端失败或返回包含已知身份值的内容时，使用本地结果，不返回供应商错误正文。
- 人数阈值及字段白名单是该固定演示场景的保护措施，不能单独证明匿名化；本功能未实现差分隐私。
- **本页策略仅作用于展示台任务，原有智能预测、Agent、导出等入口保持原有行为。**本功能不宣称全项目已完成隐私改造。
- 原始样本仅用于页面内对照，导出的执行记录不含姓名、学号、支持记录或答案正文。
- 新增接口提供匿名访问，因为当前项目使用模拟登录，且接口只允许服务端虚构样本；设有每IP每分钟30次限制。以后接入真实数据之前，必须增加真实登录及按角色、对象校验权限。

## 可选云端辅助

如需真实云端演示，由部署人员在 `backend/.env` 中启用：

```env
PRIVACY_DEMO_ALLOW_CLOUD=True
PRIVACY_DEMO_MIN_GROUP_SIZE=5
```

同时需要原有 `PREDICTION_LLM_ENABLED`、API密钥、模型和服务地址有效。重启后端后，页面才会开放「云端辅助」选项。

选择云端辅助并执行，才会真实请求已配置的模型服务，可能产生原有服务商费用。本次开发验证只模拟模型传输，不消耗模型额度。

## 精确回滚到本次修改前

本次修改前保存了实际磁盘内容，**包括原先尚未提交的修改**，不是恢复到旧Git提交。

回滚点：`.local-backups/privacy_collaboration_before_20261117/`。

1. 先停止正在运行的前端、后端服务。
2. 双击项目根目录的 **`回滚隐私协同功能.bat`**。
3. 重新启动项目，刷新浏览器。

也可以在项目根目录执行：

```powershell
& .\backend\.venv\Scripts\python.exe .\.local-backups\privacy_collaboration_before_20261117\checkpoint.py restore
```

回滚会先将这些路径的当前版本保存到 `.local-backups/before_privacy_rollback_时间/`，再恢复被修改文件，删除本次新增文件。仅处理清单内12条路径，不重置Git历史、暂存区，也不修改数据库、Excel、`.env`及其他文件。

备份内 `baseline.zip` 还保留了修改前173个项目文件，可按需提取。无需执行 `git reset --hard` 或 `git clean`。

本次功能没有数据库迁移，也不写学生业务数据。若日后部署时重新生成了 `dist`，代码回滚后应重新构建；本次开发构建输出位于忽略目录 `backend/tmp/privacy-build`。

仅检查备份完整性：

```powershell

```
